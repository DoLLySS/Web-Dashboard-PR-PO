## 3. ยังไม่ได้ทดสอบ

- Flow, SharePoint และปลายทาง Master-List **จริง** (รูปแบบข้อมูลที่แอปส่งให้ Flow ทั้งไฟล์และแถวเป็นแบบที่เรากำหนดเอง ยังไม่เคยยืนยันกับ Flow ที่ IT สร้าง)
- **ข้อมูลจริง** (ไม่อยู่ในเครื่องที่ทำงาน เข้าถึงไม่ได้)
- **เซิร์ฟเวอร์ Linux จริง** (systemd, nginx, HTTPS, firewall — ตัวอย่างใน `DEPLOY.md` ยังไม่ได้ลอง)
- **หลายผู้ใช้พร้อมกัน**
- ขั้น `pip install` ใน venv ของโฟลเดอร์จริง
- โหมด Desktop export (`LOCAL_DESKTOP_EXPORT=1`) ในเบราว์เซอร์

## 4. ข้อควรรู้

1. **กดดาวน์โหลดเร็ว ๆ ติดกัน:** กด Export CSV แล้ว Export Excel ทันทีก่อนหน้าวาดใหม่ ปุ่มที่สองอาจไม่ดาวน์โหลด และ log ขึ้น `Deferred file not found` (น่าจะเป็นพฤติกรรมของ Streamlit ยังไม่ได้ตรวจสาเหตุ) รอให้หน้าวาดใหม่ก่อนก็ได้ตามปกติ
2. **แคช 60 วินาที:** หน้าเว็บแคชข้อมูลไว้ 60 วินาที ถ้าแก้ฐานข้อมูลจากนอกแอป ตารางจะไม่เห็นจนกว่าจะบันทึกผ่านแอปหรือแคชหมดอายุ และต้องรัน Streamlit **โปรเซสเดียว** เท่านั้น
3. **ส่งไฟล์ล้มกลางชุด:** ไฟล์ในเครื่องครบเสมอ แถวมีลิงก์ของไฟล์ที่ส่งสำเร็จ ไฟล์ที่เหลือไม่ถูกส่ง ผู้ใช้เห็นข้อความตอนอัปโหลดเท่านั้น (ไม่มีแถบเตือนค้างในตาราง) ถ้าอัปโหลดชุดเดิมซ้ำ จะส่งทุกไฟล์ใหม่และไฟล์ที่เคยสำเร็จซ้ำบน SharePoint ได้
3.1 **Flow ช้าหรือตอบเพี้ยน:** ถ้า Flow ตอบช้าจนแอปเลิกรอ (timeout), ตอบ 502/504, เชื่อมต่อหลุดระหว่างส่ง หรือตอบ 2xx ที่ไม่มี `fileUrl` Flow อาจสร้างไฟล์ไปแล้ว แอปจะไม่ส่งซ้ำเอง (กันไฟล์ซ้ำ) และบอกให้ตรวจในไลบรารีก่อน แอปส่ง `requestId` ให้ Flow ใช้กันสร้างซ้ำ ส่วนการส่งซ้ำด้วยมือหลังกรณีดังกล่าวยังต้องอาศัย Flow ตรวจ `requestId` หรือผู้ใช้ตรวจไลบรารี
4. **Rollback โค้ด:** ย้อนโค้ดจากชุดสำรองแล้ว ไฟล์ที่รุ่นใหม่เพิ่มมา (22 ไฟล์ในการซ้อม) จะไม่ถูกลบ ไม่กระทบรุ่นเก่า
5. **ไม่มีล็อกอิน** ใครเข้า URL ได้ก็ดู แก้ ลบได้ และไฟล์ใน `/app/static/...` เปิดได้โดยไม่ล็อกอิน ห้ามเปิดพอร์ตสู่อินเทอร์เน็ต
6. **ชุดสำรอง `--code` มี `.env`** (รหัสลับ) ต้องเก็บในที่ปลอดภัย
7. เกณฑ์ค้าง 14 วันนับจากวันอัปโหลดเป็นการชั่วคราว รอเจ้าของงานยืนยัน (`OVERDUE_RULE` ใน `config/constants.py`)
8. ไฟล์ที่จับคู่ PR ได้และไม่มีคำบอกว่าเป็นเอกสารอื่น ถูกนับเป็นใบกำกับ จึงเปลี่ยนสถานะผิดได้
9. ไฟล์ที่รอเลือกแถวเก็บในเซสชันเบราว์เซอร์ รีเฟรชแล้วหาย
10. ห้ามใช้ `DB_JOURNAL_MODE=WAL` ถ้าโฟลเดอร์อยู่บน OneDrive
